# 前端开发说明

Vue 3 + Vite。用户端和管理端共用网站、登录会话和后端；页面根据账号权限显示不同入口，后端负责最终权限判断。普通用户从“预约”进入物品或地点预约，从“我的”进入各自独立的预约、反馈和资料页面；管理端包含库存、地点、归还核验、账号、审核、公告和反馈。

云端发布通过 Nginx 提供静态文件并转发 `/api`，不运行 Vite 开发服务器。发布时使用全新的构建输出目录，避免上传本机旧 dist 中残留的历史资源。当前公网IP测试入口为 `https://8.155.137.77`；原回环地址仍需本机加密隧道。部署边界见[部署说明](../deploy/README.md)和[公网入口记录](../docs/2026-11-24%20公网入口配置记录.md)。

## 本地启动

先按根目录 README 启动 PostgreSQL 和后端，确认 `http://127.0.0.1:8080/api/v1/health` 返回正常。再在项目根目录执行：

```powershell
cd frontend
npm ci
npm run dev
```

打开 Vite 输出的地址。开发服务器将 `/api` 代理到本机 8080；要临时调整目标，在启动 Vite 的同一终端设置 `API_PROXY_TARGET`。前端不直接连接数据库，也不保存真实密码。

```powershell
npm test
npm run build
```

## 当前功能和注意事项

- 物品、地点、预约、领取、归还、审核、日志、公告、反馈及账号资料均有真实接口；请求失败应显示错误，不能当成成功。
- 账号分普通用户、审核员、系统管理员。系统管理员创建账号、分配其他人的权限；账号和姓名本人不能修改。普通用户也可在“我的”维护联系资料和头像。
- 存放地点与可预约地点分开维护；物品预约可跨天，地点预约按开放时间和整点提交。具体限制由后端校验。
- 用户端和管理端支持已打开页面标签；切换可保留页面状态，关闭标签后重新进入会重建，刷新整个网页会重置标签。
- 顶部栏和导航保持在视口内，页面内容独立滚动；矮屏下侧栏可单独滚动。手机菜单固定在页头下方，展开菜单过长时内部滚动。弹窗打开时锁定背景内容，关闭后恢复，键盘聚焦内容区后可翻页滚动。
- 布局包含响应式样式，但后续改动需重新检查 320/390 等窄屏和真实手机，尤其拍照、登录及弹窗。
- `VITE_ENABLE_MANAGEMENT_DEMO=true` 只用于本地开发演示；不要以演示数据代替联调或验收。日常调试使用真实后端。

主要代码：`src/App.vue` 负责导航与登录态；`src/features/` 和 `src/components/` 为页面；`src/lib/api.js` 为 API；`src/styles.css` 为共享样式。页面改动涉及接口时同步检查 `../contracts/openapi/openapi.yaml`。

## 页面更新与公告提醒

列表页已移除手动刷新按钮，返回已打开的页面标签时重新读取列表。通用浮窗使用右上角叉号关闭，保留键盘 Escape 和可访问名称。普通页面仅保留标题、副标题及业务所需的内容、字段与状态，撤去额外说明小字。

登录或恢复有效会话后，如有未读的已发布公告，自动打开公告栏；关闭时确认已展示的版本。阅读记录由后端按账号保存，接口失败不会阻止登录。

## 分组导航与高级搜索

用户端按使用频率排列为“预约”（物品预约、地点预约）、“我的”（我的预约、我的反馈、我的资料）和独立的存放地点入口。后台优先展示审核工作台、归还核验、未归还提醒，再展示“管理”（库存、地点、账号、公告）及用户反馈。分组可展开和收起，子页面拥有独立的已打开标签和页面状态；手机通过“菜单”展开同一导航树，选中后收起。

物品页高级搜索支持关键词、存放地点、普通/贵重类型、当前库存与排序。编辑条件后点击“搜索”才应用，“重置”恢复全部条件；分页和返回页面使用已应用条件。类型与排序均传给后端，在筛选后计算总数、排序和分页；当前库存不等同于某预约时段的余量。

## 预约到期提示

2026-11-16更新整合了借还照片分批选择与移除、归还核验照片放大及二次确认、审核批准确认、预约日志状态与关键字筛选。借还四阶段进度位于预约详情，列表仍使用紧凑卡片；上传或核验提交中禁止重复提交与关闭。日志分页使用已经查询的条件。详见[整合复核](../docs/2026-11-16%20PR16和PR17整合复核.md)；交付内容见[更新说明](../docs/2026-11-16%20更新说明.md)。

“我的预约”显示自动过期的原因，并提供“归还提醒”浮窗（仅本人）；已领取物品超过应归还时间也在卡片上提示提交归还。后台“归还核验”下方增加“未归还提醒”，审核员和系统管理员可查看全员提醒与实物编号。提醒页面每30秒读取一次，切换返回也更新；已提交核验或已完成归还的不作为当前未归还提醒展示，核验驳回后重新显示。后台worker需持续运行才能生成新提醒；此功能不发送短信或邮件。
