# 独立任务服务：第一周骨架

该服务可单独启动，用于验证 worker 与核心 API 是两个独立进程。当前只提供健康检查；内部认证、任务领取和执行尚未接入，`POST /jobs/run` 会明确返回 503，**不会假装任务成功**。不能用第一周骨架证明课程的两台机器验收已经完成。

## 启动

需要 Node.js 22 或更新版本。在 `worker/` 目录运行：

```powershell
node server.mjs
```

另开 PowerShell 验证：`Invoke-RestMethod http://127.0.0.1:8091/health`。

默认只绑定本机 `127.0.0.1:8091`。后续两机演示时由部署负责人设置 `WORKER_HOST`、`WORKER_PORT`，先完成内部认证与防火墙配置。

worker 不连接、不写入核心 PostgreSQL；通过后端受保护的内部 API 领取和提交任务。首批任务：待审申请超时、预约到期、未归还提醒。每次领取需要任务 ID 和租约；提交结果需要幂等键。失败使用有限次数重试与退避，超过上限记入处理日志并交给管理员排查。具体调用、认证和错误响应见 [独立任务服务接口草案](../docs/独立任务服务接口草案.md)。
