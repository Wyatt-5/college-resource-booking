# 账号与权限

当前界面区分三类账号：

| 身份 | 权限 |
| --- | --- |
| 普通用户 | 浏览资源，提交和管理自己的预约，确认领取和归还。 |
| 审核员 | 使用预约功能；管理全部地点与物品，审核他人申请、核验归还、查看预约日志。不能创建或管理账号。 |
| 系统管理员 | 拥有审核员功能，还可以创建账号、调整其他账号身份和停用其他账号。 |

系统管理员和审核员都不能审核自己提出的申请。账号由系统管理员统一创建，用户不能自行注册。停用账号保留预约与审计记录；有未完成预约或借还时需先处理。系统管理员不能停用或修改自己的授权。

## 旧权限兼容

数据库中已有的 `COUNSELOR_ADMIN`、`RESOURCE_MANAGER` 授权不会自动删除：用户界面与权限检查把它们兼容为审核员。**原只管理部分地点的资源管理员因此能管理全部地点**，上线前应由系统管理员核对并调整这些账号。保存身份时，只会写入系统管理员、审核员或普通用户的当前表示。

审核申请按提交顺序展示，由审核人决定冲突时段的归属，不再区分辅导员优先身份。后端仍检查账号状态和角色，页面隐藏按钮不作为授权依据。

## 账号管理边界

停用不会物理删除账号或历史记录。系统管理员在“新增账号”填写相同账号和原姓名可重新启用：需设置新密码，旧管理权限被清除，历史记录和已有个人资料保留；若选择部门则更新部门。姓名不同不能复用该账号。密码变更或重新启用后，旧会话在下一次受保护请求时失效；这不是向客户端主动推送退出通知。

用户可自行填写部门、邮箱、手机号和头像，姓名与登录账号不由本人修改。系统管理员可新增部门选项。头像对已登录用户可见，个人联系方式仅本人资料接口返回；上传照片及资料不应随代码提交。
