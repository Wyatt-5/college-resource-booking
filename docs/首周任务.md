# 首周任务（六人并行）

下列任务可直接复制到 GitHub Issues。每个任务由负责的搭档细化为 1–3 天可合并的小任务。

| 人员 | 首周交付 | 验收方式 |
|---|---|---|
| 1 号（组长） | 可启动后端、数据库迁移、登录与角色权限设计；维护接口契约 | 组员在自己的电脑上按 README 启动；提交权限状态图 |
| 2 号 | 用户端导航、登录页和“我的预约”页面骨架 | 手机与电脑宽度可操作；模拟响应结构与契约一致 |
| 3 号 | 地点、物品、实物编号及照片接口设计与第一批实现 | 数据库有迁移脚本；地点真实接口可读 |
| 4 号 | 物品列表和管理员上架页面骨架 | 页面能用模拟数据展示并提交表单 |
| 5 号 | 预约状态图、时间冲突与单人审批接口设计 | 写出并发预约、禁止自审的测试用例 |
| 6 号 | 会议室日历、审核工作台页面骨架；任务服务通信方案 | 页面可展示示例预约；画出跨机器调用图 |

首周共同会议只决定四件事：预约状态、角色授权、接口请求/响应、物品与会议室时间冲突规则。随后按搭档并行开发，不等待某一个人完成全部后端。
